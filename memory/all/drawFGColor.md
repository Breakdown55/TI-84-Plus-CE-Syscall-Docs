### Address: $D026AC

Stores the current RGB 565 foreground drawing color. See also [DrawRectBorder](../../syscalls/all/DrawRectBorder.md), [DrawThickRectBorder](../../syscalls/all/DrawThickRectBorder.md).

### Size: 2 bytes
